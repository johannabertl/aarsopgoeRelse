# aarsopgoeRelse
Forberedelser til årsopgørelsen

# DISCLAIMER

Dette repo har intet at gøre med mit arbejde i Skattestyrelsen. Repo'et indeholder værktøjer programmeret i min fritid til min egen årsopgørelse. Tilpas koden til dit brug - det er dit eget ansvar at indberette korrekt.

## Antal dage med befordringsfradrag

R-scriptet hjælper med at beregne antallet af dage med befordringsfradrag per måned. Det kraver at man har oprettet homeoffice-dage, ferie, sygdom etc. i sin kalender på en systematisk måde og kan eksportere kalenderen som CSV-fil (fx. fra outlook).
